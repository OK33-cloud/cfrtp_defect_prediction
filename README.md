# CFRTP（炭素繊維強化熱可塑性樹脂）の内部欠陥予測

![Python](https://img.shields.io/badge/Python-3.10-blue.svg)

## 概要

3Dプリンタで作るCFRTP製品は、表面を見ても内部の空洞（ボイド）は分かりません。これまではX線CTで内部を確認していましたが、時間と費用がかかります。

この研究では、印刷中に撮ったレーザの表面画像から、内部の空洞がどこにあるかを画像として予測します。予測には、画像の領域を塗り分けるU-Net系のモデルを使います。

## 何を比べたか

モデルは1から12まで作っています。モデル3は作っていません。変えた点は次のとおりです。

| モデル | 変えたこと |
| --- | --- |
| 1 | 基準のU-Net。表面画像とX線画像の位置合わせはしない |
| 2 | レーザ画像とX線CT画像の位置を合わせる |
| 4 | 位置合わせに加え、外れたデータを除く |
| 5 | 注目すべき場所を強調するAttentionを足す |
| 6 | 学習の損失をFocal Lossにする |
| 7 | 印刷条件をFiLMで入れ、見落としにくい損失にする |
| 8 | 画像の特徴を取る部分をConvNeXt-Tinyに替える |
| 9 | 特徴を取る部分をSegFormer-B0に替える |
| 10 | 構造をU-Net++に替える |
| 11 | モデル8と同じ構造で、空振り（誤検出）を重く見る |
| 12 | モデル8と同じ構造で、空振りと見逃しを同じ重みにする |

最初に公開した時点では、位置合わせによってF1スコアが0.37から0.44に上がった、と報告していました。その後、全モデルを同じテスト画像で測り直しています。この共通の測り方では、位置合わせだけのモデル2はF1スコア0.37で、基準のモデル1とほぼ同じです。スコアが大きく上がったのは、特徴抽出をConvNeXtにしたモデル8以降です。

## 結果

数値は、学習に使っていないテスト画像での画素単位のF1スコアです。1に近いほど、予測した空洞の位置がX線CTの正解に近いことを意味します。

単体で最も高いのはモデル12の **0.518**、次いでモデル8の **0.511** です。

複数モデルの予測確率を平均するアンサンブルでは、次の結果になりました。

| 組み合わせ | F1スコア | 適合率 | 再現率 |
| --- | ---: | ---: | ---: |
| モデル1〜12の平均（モデル3は含まない） | 0.477 | 0.431 | 0.535 |
| **モデル8とモデル12の平均** | **0.557** | **0.521** | **0.599** |

全員を平均すると、よいモデルの予測が他のモデルに薄まり、モデル8や12の単体より低くなります。検証用の予測で組み合わせを選ぶと、モデル8とモデル12の2つが最もよく、テストでのF1スコアは **0.557** です。

図と、各モデルの詳しい説明は [Notebook/03_モデル1から12とアンサンブル.ipynb](Notebook/03_モデル1から12とアンサンブル.ipynb) にまとめています。

## 限界

画素がぴったり一致する割合は、最良の組み合わせでもF1スコア0.56程度です。X線CTの完全な置き換えにはまだ届いていません。モデル3（外れ値除去だけを単体で見る実験）は実施していません。
